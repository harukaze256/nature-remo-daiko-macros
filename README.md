# Nature Remo / DAIKO macro generator

DAIKOの独自BLEサービス向けに、Nature Remo機器拡張マクロのXMLをローカル生成するツールです。Python 3.9以上の標準ライブラリだけで動作します。

Pythonソースとテンプレートには実機の接続コードを含めません。登録用のon.xmlとoff.xmlは、利用者の明示的な了承により、接続コードを含む実機用データを公開しています。Bluetoothアドレス、器具固有名、LANアドレス、アクセストークン、利用者名、ローカルパスはXMLに含めていません。`*.xml.template`には実行用データを持たないテンプレートだけを置いています。

## ローカル生成

リポジトリの外に非公開JSON設定を用意します。設定項目は次のとおりです。

| キー | 内容 |
|---|---|
| `sid` | 必須。実機から取得した5桁のASCII接続コード |
| `last_color` | 任意。13〜240の光色値。既定値13 |
| `last_brightness` | 任意。13〜240の明るさ値。既定値240 |

設定ファイルと出力先の両方をソースディレクトリ外に指定します。

```text
python generate.py --settings <PRIVATE_SETTINGS_JSON> --output <PRIVATE_OUTPUT_DIRECTORY>
```

既存の出力ファイルは上書きしません。ネットワークへの送信は行いません。接続コードをコマンドライン引数や環境変数へ直接入れる必要もありません。

## 公開範囲とNature Homeへの登録

on.xmlとoff.xmlには、接続コードが16進数の送信データとして含まれます。これらは公開に了承した特定の照明向けです。他の照明でそのまま使う場合の動作は保証しません。

Nature Homeで対象のBLE家電を開き、「＋」から名前とPUBLIC GITHUB URLを設定します。「動作のテスト」で実際の反応を確認し、保存してください。

- 点灯用は、このリポジトリのon.xmlのGitHubファイルURLを指定します。
- 消灯用は、このリポジトリのoff.xmlのGitHubファイルURLを指定します。

## 通信内容

独自サービス`ffb0`の`ffb2`に20バイトをWrite With Responseで送信します。先頭5バイトはASCIIの接続コード、制御バイトは`c0`です。消灯は明るさ`ff`を用い、点灯はローカル設定値を使います。

ONの明るさ・光色は生成時に固定されます。フレーム内の時刻も生成時の値になるため、照明タイマーとの併用は未検証です。機種ごとの通信仕様・適合性は利用する実機で確認してください。

## テスト

```text
python -m unittest -v test_generate
```

テストは合成データを使い、実機やネットワークへ接続しません。

## 明度・光色の向き

制御値が小さいほど明るく、寒色になります（明度100%＝13、0%＝240。寒色100%＝13、暖色0%＝240）。明度%は制御スケールの相対値であり、測定した光束や照度ではありません。色温度のK値は器具型番未確認のため示していません。同じURLのXMLでも登録済みの内容は更新されない場合があるため、変更時はNature Homeの既存ボタンの編集画面で動作テスト・保存を行います。

明度10・50・100% × 暖色・中間・寒色の旧プリセット（scene-*.xml）は、下の生活シーン用ボタンへ置き換えたため削除しました。

## 生活シーン用ボタン

PCアプリのスライダーで評価した値を、明度・色温度（0〜100%、100%が最も明るい／寒色）に固定したONマクロです。

| ファイル | ボタン名 | 明度 | 色温度 | 送信値（光色/明度） |
| --- | --- | --- | --- | --- |
| level-b080-c100-active.xml | 活動 | 80% | 100% | 13 / 58 |
| level-b040-c020-rest.xml | 休息 | 40% | 20% | 195 / 149 |
| level-b001-c005-sleep.xml | 入眠 | 1% | 5% | 229 / 237 |
| level-b000-c005-nightlight.xml | 常夜灯 | 0% | 5% | 229 / 240 |

明度0%は制御スケールの最も暗い点灯で、消灯（255）ではありません。照明は明度の生値238（0xEE）を消灯として扱うため、1%は計算値238の代わりに237を送ります。
